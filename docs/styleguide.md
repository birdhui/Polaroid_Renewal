# Style Guide

> **관리: 모진아** (작업 브랜치: `style/design-system`)
> 공통 폰트·컬러·스타일 기준과 로고·파비콘을 정리하는 문서입니다. 아래 항목은 **디자인 확정 전 빈 틀**입니다.
> 값이 확정되면 이 문서와 `src/shared/styles/variables.css`를 같은 PR에서 함께 고칩니다.

## 3. 간격 · 레이아웃

현재 `variables.css`에 4px 단위 임시 간격(`--space-1` ~ `--space-8`)이 있습니다. 확정되면 교체합니다.

## 4. 로고 · 파비콘 · 브랜드 공통 에셋

| 에셋 | 위치 | 비고 |
| --- | --- | --- |
| 파비콘 | `public/favicon.svg` | 현재 임시 파일 |
| 로고 | `src/assets/shared/` 또는 `public/assets/shared/` | 확정 전 (헤더 로고는 현재 텍스트) |
| 공통 폰트 · 아이콘 | `src/assets/shared/fonts/`, `src/assets/shared/icons/` | 확정 전 |

페이지별 이미지·영상은 각 페이지 담당자가 관리합니다.

## 5. 사용 규칙

- 컴포넌트에서 색·간격·폰트를 하드코딩하지 않고 `variables.css`의 CSS 변수를 사용합니다.
- 새 토큰이 필요하면 모진아에게 요청합니다. 모진아가 `style/design-system`에서 추가하고 PM이 검토합니다.
